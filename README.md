# JS Bookmarks Manager App

A bookmark manager with categories. Save, view, and delete bookmarks in your browser.

## Features

- Add bookmarks with name and URL
- Categories: News, Entertainment, Work, Miscellaneous
- View bookmarks by category
- Delete bookmarks
- Data persists in localStorage

## Technologies

- HTML5
- CSS3 (minimalist black and white design)
- JavaScript (Vanilla JS)
- LocalStorage API

## Installation

1. Clone the repository:
```bash
git clone https://github.com/antonmakarovv/JS-Bookmarks-Manager-App.git
```

2. Open `index.html` in your browser

## Usage

1. Select a category from the dropdown
2. Click "View Category" to view bookmarks in the category
3. Click "Add Bookmark" to add a new bookmark
4. Fill in the name and URL, then click "Add Bookmark"
5. To delete, select a bookmark and click "Delete Bookmark"
